# SQL injection detection with KNN, SVM, Random Forest, and XGBoost: Kaggle benchmark, sqlmap test, and operator normalisation

Code, test strings, and results for the article

> S. Arizal, E. G. Zinedine, Sumanto, and D. Puspitasari, "Comparative Analysis of KNN, SVM, Random Forest, and XGBoost Algorithms for SQL Injection Attack Detection in Web Applications," *Journal of Information Systems and Informatics*, [volume, issue, pages, DOI to be added].

Archived version: [DOI_ZENODO]

## How to reproduce

### Option A: Google Colab (as in the article)

1. Open `notebooks/SQLi_Comparative_Study_REV9.ipynb` in Colab and run all cells. It downloads the dataset with `kagglehub`, installs sqlmap 1.10.11, generates the test strings, runs the full pipeline, and downloads `results_sqli.zip`.
2. Open `notebooks/SQLi_Baselines_OperatorNorm_REV10.ipynb` and run all cells. It downloads `results_rev10.zip`.

The article's results come from a Colab CPU runtime with 2 cores, Python 3.13.16, scikit-learn 1.6.1, XGBoost 3.4.1, NumPy 2.4.6, pandas 2.2.3, and SciPy 1.16.3. Other scikit-learn versions can change the Random Forest results slightly.

### Option B: local

```bash
pip install -r requirements.txt
python -c "import kagglehub; print(kagglehub.dataset_download('sajid576/sql-injection-dataset'))"
# path to the sqlmap XML templates installed by pip
SQLMAP_XML=$(python -c "import sqlmap, os; print(os.path.join(os.path.dirname(sqlmap.__file__), 'data', 'xml'))")
python src/gen_sqlmap.py "$SQLMAP_XML" data/sqlmap_payloads.csv
python src/sqli_pipeline.py <path>/Modified_SQL_Dataset.csv data/sqlmap_payloads.csv results/results_sqli
python src/sqli_baselines_norm.py --data <path>/Modified_SQL_Dataset.csv --sqlmap data/sqlmap_payloads.csv \
    --hp results/results_sqli/best_hyperparameters.csv --ref results/results_sqli --out results/results_rev10
```

`sqli_baselines_norm.py` downloads the CRS rule file from the `v4.30.0` tag of github.com/coreruleset/coreruleset unless `--crs <local file>` is given.

## Notes on the result files

- Files that contain Kaggle payload text (the pre-processed dataset and the test split) are not included. They can be regenerated with the scripts. `results_sqli/test_predictions_80_20_no_text.csv` keeps the labels and predictions without the text.
- `results_rev10_supplement/false_alarms_by_input_type.csv` breaks the false alarms down by benign input type (complete SQL statements vs other inputs), as reported in Sections 3.1.9 and 3.2.3. It was produced by the current version of `sqli_baselines_norm.py` in a separate run (scikit-learn 1.9.1). The libinjection and CRS rows are deterministic and match the Colab run exactly. The SVM row matched the Colab predictions as well.
- `results_rev10_supplement/spaced_equals_check.json` records the share of SQLi test payloads with a spaced equals sign (80.53%).
